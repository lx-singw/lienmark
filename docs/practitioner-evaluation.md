# Practitioner evaluation worksheet

Status: **not yet performed**. This worksheet contains no customer endorsement or measured savings.

Ask a production clearance professional to evaluate a fictional or authorized production packet. Obtain permission before recording or attributing their comments. Keep their identity, confidential documents and raw notes private. No outreach is sent by the application or by this worksheet.

## Questions to resolve

- Does a changed duration, scope, asset or supporting source reopen the right decisions? Which dependency did the system miss or overstate?
- Can the reviewer explain every preserved approval and every reopened claim from the displayed record?
- Are the questions specific enough for the producer to supply the correct document?
- Does the draft Exceptions Schedule contain the fields the recipient actually needs? Which fields are missing or misleading?
- Where would this fit into the practitioner's existing tools, and which part would they trust only after further validation?

## Small comparative exercise

Use two comparable revision packets, with baseline decisions and ground-truth affected claims established independently by the practitioner. Counterbalance order when possible: manual review first for one packet, Lienmark first for the other. Record the number of occurrences, changes, dependency edges and available documents so the comparison is interpretable.

| Measure | Existing process | With Lienmark | Evidence / limitation |
|---|---|---|---|
| Active review minutes | Not measured | Not measured | Separate waiting time from human effort |
| Correctly reopened decisions | Not measured | Not measured | Compare with independent review |
| Incorrectly preserved decisions | Not measured | Not measured | Treat missed changes as substantive failures |
| Unnecessarily reopened decisions | Not measured | Not measured | Measure repeated work |
| Time to identify missing document | Not measured | Not measured | Keep the same available information |
| Schedule corrections required | Not measured | Not measured | Recipient's actual corrections |
| Provider calls and elapsed time | Not applicable | Not measured | Export the execution record |

Record sample size, practitioner role, task order, input differences and exact observations. A small exercise is directional evidence, not generalizable legal-cost savings. Publish quotations only with permission and preserve their meaning. Do not invent a testimonial if no practitioner is available.
